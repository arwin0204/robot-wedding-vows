# One-Line Robot Wedding Vows

Entry for the make.fun bounty **One-Line Robot Wedding Vows**
(`u-kreutzx-one-line-robot-wedding-vows-a154ba4b`): the funniest single
line of wedding vows a robot couple could say, at most 160 characters.

## Entry

> I vow to love you through every update, every reboot, and every low-battery warning — and if my circuits fail, reboot me, because I'd choose you again.

(151 characters, one line.)

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. The program is
deterministic — every run writes exactly the same text — and uses no
network and no dependencies beyond the Python 3.13 standard library.
